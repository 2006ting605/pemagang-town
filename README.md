# 貝瑪崗小鎮模擬 Pemagang

一個虛構的喜馬拉雅山腳小鎮，仿照 Park 等人〈Generative Agents: Interactive Simulacra of Human Behavior〉（UIST 2023）的代理人架構。

十位居民各有人設、記憶流、記憶檢索（新近性 + 重要性 + 相關性）、反思與每日計畫。模擬從第 1 天早上 6 點跑到第 2 天晚上 11 點，觀察兩則一開始只有一個人知道的消息如何在鎮上傳開：

- 卓瑪打算在第 2 天傍晚 5 點於茶館辦燈節茶會（對應論文的情人節派對）
- 帕桑打算參選村代表（對應論文的鎮長選舉）

## 小鎮與居民

- **十位居民**：茶館老闆娘卓瑪、客棧老闆帕桑、嚮導學徒妮瑪、小學老師拉姆、茶園工頭蘇曼、衛生站的安尼爾、貝瑪寺的格桑喇嘛、水磨坊的瑪雅、郵局的比卡什，以及從台灣來研究茶樹的曉雯。每個人都有自己的服裝與畫像。
- **看得到屋內**：建築物是沒有屋頂的俯視圖，茶館、客棧、學校、寺院、衛生站、郵局、水磨坊、製茶廠和住家都有各自的擺設，居民會從門口走進屋裡活動。
- **真實的道路**：車道、村裡小徑、上山的之字形石階，以及過河的經幡吊橋。居民會沿著路、用各自的速度走路。
- **日夜與天氣**：晚上有人的屋子會亮燈；頁面上方顯示時間、天氣和日期。

## 使用方式

直接用瀏覽器開啟 `index.html`，或透過 GitHub Pages 瀏覽。整個網頁是單一檔案，不需要安裝任何東西。

- 按「播放」開始模擬，可切換 1～8 倍速，或按「+10 分」一步一步前進
- 右側「認識居民」顯示每個人此刻在哪裡、正在做什麼
- 點居民可以查看他的計畫（日計畫 → 小時區塊 → 10 分鐘動作）、記憶流與反思
- 在記憶流輸入問題，查看每筆記憶的檢索分數
- 「資訊擴散」分頁顯示消息傳播曲線、人際網路變化，以及誰知道什麼

## 互動

- **介入世界**：讓某棟建築失火、下大雨、市集特價、巴士誤點，或放上自訂事件（例如「河邊出現一頭雪豹」）。看到的居民會記住、改變計畫，並把消息傳給別人。
- **扮演居民**：輸入名字後搭巴士進鎮，點地圖移動，走到居民身旁就能跟他說話。你告訴他的消息會寫進他的記憶流，再由他傳出去。
- **拖曳居民**：按住居民拖到別的地點，他會在那裡待一小時，再回到原本的行程。
- **居民之間的互動**：對話會以泡泡出現在地圖上；居民在路上遇到熟人會打招呼、順路時會一起走，休閒時段也會三四個人聚在一起聊天。
- **內心聲音**：對某位居民寫下一句話，會以高重要性寫入他的記憶流。

## 論文附錄的對應

- **附錄 A 智慧體摘要描述**：以「核心特徵」「目前的日常工作」「對近期生活進展的感受」三個查詢檢索記憶後整理成摘要並快取，每天早上更新。
- **附錄 B 25 題訪談**：分成自我認知、記憶、計畫、反應、反思五類，改寫成貝瑪崗的情境；可以單題提問，也可以一次跑完整份訪談。

## 說明

在 GitHub Pages 上，居民的日常行為與對話由瀏覽器內的規則引擎產生。訪談、居民回覆你的話、Claude 寫對話、Claude 反思與摘要整理會改用本機模式（依檢索到的記憶與計畫回答，無法處理需要推理的問題）；這些功能只有在 claude.ai 的 Artifact 中開啟時才會呼叫 Claude。
